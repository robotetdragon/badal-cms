# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅ Yes    |

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Send a description to: **security@badal-cms.com**  
Or open a [private GitHub security advisory](https://github.com/badal-cms/badal/security/advisories/new).

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will respond within **48 hours** and aim to release a fix within **7 days** for critical issues.
