# Badal 🎙️

**Badal** — Lightweight, database-free podcast CMS. Pure PHP, flat files, RSS feed, stats, customizable themes. From the Latin *batare* (to open one's mouth) — the freedom to speak.

> Episodes in Markdown + YAML · RSS compatible with Apple Podcasts & Spotify · Protected admin interface · 4 languages

## ✨ Features

- **Zero database** — episodes stored as `.md` files with YAML frontmatter
- **RSS feed** — fully compatible with Apple Podcasts, Spotify, Pocket Casts, Overcast
- **Admin UI** — clean dark interface with live preview
- **Themes** — 14 Google Fonts, custom colors, presets
- **Stats** — play counts per episode, interactive charts, CSV/PDF export
- **Import** — migrate from any existing podcast via RSS feed
- **Security** — bcrypt, CSRF, rate-limiting, session fingerprinting
- **4 languages** — Français, English, Español, Português
- **Auto duration** — ffprobe extracts audio duration on upload
- **Update checker** — notified when a new version is available

## 🚀 Installation

### Requirements

- PHP 7.4+ (tested on 8.4)
- Apache with `mod_rewrite` (or Nginx equivalent)
- `ffprobe` recommended (for auto duration detection)
- No database required

### 1. Upload files to your server

```
your-domain.com/podcast/
├── setup.php
├── .htaccess
├── admin/
├── core/
├── public/
└── ...
```

### 2. Run setup

Open `https://your-domain.com/podcast/setup.php` in your browser.

- Choose your language (FR / EN / ES / PT)
- Set your admin username and password
- Badal auto-detects your base URL

**No config file to edit.**

### 3. Delete setup.php

```bash
rm setup.php
```

### 4. Access admin

`https://your-domain.com/podcast/admin/`

## 🔒 Security

| Feature | Implementation |
|---------|----------------|
| Password | bcrypt cost 12 |
| Session | 8h expiry, UA fingerprint |
| CSRF | Token on all POST forms |
| Rate limiting | 5 attempts / 15 min lockout |
| Upload | finfo MIME validation |
| Headers | CSP, HSTS, X-Frame-Options |
| Directories | Blocked by `.htaccess` |
| Audio proxy | Path traversal protection |
